## 2. B9.36 Question Review 完整单题工作流

### 数据与 contract

- migration：`0014_question_review_workflow.sql`
- 表：`question_override_revisions`
- 状态：`draft / pending_review / approved / rejected`
- shared contract 增加：
  - revision snapshot
  - field-level diff
  - active revision/history
  - save/submit/review/rollback requests
- RBAC 增加 `question_review:approve`。

### 行为

- `PATCH .../override` 只保存 draft，不直接改变学生读取。
- `POST .../override/submit` 提交审批。
- `POST .../override/approve` 应用 snapshot 到 effective override。
- `POST .../override/reject` 驳回且不应用。
- `POST .../override/rollback` 创建新的 approved revision，保留完整历史。
- effective version、draft version 和 question row lock 共同处理并发。
- Practice/Wrongbook/Learning 只读取 approved effective override。

### Admin

- 字段级 before/after diff。
- 保存草稿、提交审批。
- 审批意见、批准、驳回。
- revision history 和回滚。

## 3. B9.37 Import Jobs Realtime Progress

### 数据与传输

- migration：`0015_import_job_events.sql`
- 表：`import_job_events`
- durable event：`queued/running/progress/succeeded/failed/cancelled/recovered`
- endpoint：`GET /api/admin/import-jobs/:jobId/events`
  - JSON event page
  - `text/event-stream`
  - `Last-Event-ID`
  - `afterEventId`
  - keepalive
  - `X-Accel-Buffering: no`

### Progress

runner/importer 报告：

- `loading_source`
- `dry_run_summary`
- `classifications`
- `questions`
- `options`
- `bank_mappings`
- terminal state

每个 progress event 持久化完整 job snapshot，因此 API 重启或浏览器重连后可从数据库补拉。

### Admin

- queued/running job 自动建立 `EventSource`。
- 实时更新 progress bar、job detail 和最近事件。
- 终态后关闭连接。
- 不支持 EventSource 的测试环境安全回退。

## 4. B9.38 Importer 性能与容量

### 优化

原 upsert 虽使用 conflict-level `IS DISTINCT FROM`，但 unchanged full import 仍会为每行进入 conflict path，产生明显 WAL 和 I/O。

现在每批数据先执行 typed incoming-row prefilter：

```sql
INSERT INTO target (...)
SELECT incoming.*
FROM (VALUES ...) incoming (...)
WHERE NOT EXISTS (
  SELECT 1 FROM target existing
  WHERE existing.id = incoming.id
    AND ROW(existing...) IS NOT DISTINCT FROM ROW(incoming...)
)
ON CONFLICT (...) DO UPDATE ...
WHERE ROW(target...) IS DISTINCT FROM ROW(EXCLUDED...)
```

- prefilter 跳过完全相同的 existing row。
- conflict predicate 保留，用于并发竞态保护。
- importer 返回四张表的 logical `writes`。
- batch progress 复用于 Import Jobs events。

### 真实 PostgreSQL 变更语义

integration test 验证：

1. 首次导入 classification/question/option：各写入 1。
2. 相同数据再次导入：各写入 0。
3. 修改 classification name、question content/searchable text、option content 后再导入：各更新 1。
4. 数据库最终值与修改后输入一致。
